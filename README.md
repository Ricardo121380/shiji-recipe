# 饭Fun · 厨房伴侣（原名：食记、饭饭）

「饭Fun」是一个轻量的中文厨房管理网页：菜谱点菜、本周菜单、冰箱库存、日用品、热量统计，数据默认保存在浏览器本地，可选登录账号做云端同步。

**线上地址（已固定，长期不变）：**

- **GitHub Pages（主地址，分享给他人用这个）**：https://ricardo121380.github.io/shiji-recipe/
- Cloudflare Pages（备用线路）：https://shiji-recipe.pages.dev/

两条线路网址长期固定，后续更新只替换内容、不改网址。菜谱数据按「网址 + 浏览器」隔离，请固定使用同一网址访问；跨线路搬家用「导出备份 / 导入备份」。详见 [AGENTS.md](AGENTS.md) 中的网址与数据约定。

## 功能

- **菜谱**：菜单与水吧两个板块；水吧饮品可设置可选温度（冷 / 常温 / 热），点单时选择；1:1 卡片配图；用时（小时/分钟）、人份、热量；食材按「名称 + 用量」结构化记录；步骤三行式呈现（提前准备标识 / 文字 / 配图），可勾选「需要提前准备」；分类与「规格」（口味、忌口等）完全自定义。
- **点菜**：菜谱、零食、外出餐都能点——选份数、规格（口味/忌口等）和就餐日期，自动排进本周菜单。
- **本周菜单**：7 天 × 早/午/晚/加餐；可在格子里添加不关联菜谱的「自定义」项（如外卖披萨，可填热量和备注）；可手动更改份数、规格、更换菜品；**勾选「已吃」才扣库存、记热量，取消勾选自动回补**；含「提前准备」步骤的菜品会标注并在前一天 18:00 通知（页面打开时）。
- **冰箱**：食材 / 速食零食 / 其他三个板块（零食可标注品牌、口味）；搜索；五档筛选（全部 / 新鲜 >7 天 / 快过期 1-7 天 / 已过期 / 无库存）；可按自填单位记热量；临期预警 + 浏览器通知；猫 / 狗能否吃分别标注；**多选食材找菜谱**：优先推荐包含全部所选的菜谱，其余部分匹配排后，命中数相同时临期食材优先。
- **购买清单**：按本周菜单（含份数）自动算缺口，按食材分类打标签可筛选；手动添加、编辑、已完成自动沉底；日用品低库存一键加入。
- **日用品库存**：与冰箱类似的库存管理（洗衣液、厨房纸等），分类可自定义，低库存提醒并可加入购买清单。
- **热量记录**：自定义每日目标；数据以本周菜单勾选「已吃」为准（按份数累计），取消勾选自动扣除。
- **菜品推荐**：根据冰箱剩余量、临期食材、今日热量余量推荐，1:1 图片展示。
- **就餐记录**：按自然月保存吃过的每一餐（含份数与规格），月初可复制或邮件发送上月清单。
- **外出就餐**：按大分类（餐馆 / 餐厅 / 其他，可自定义）和各自的小分类记录店名、热量与用时，每道菜可勾选外卖 / 堂食，可上传配图、随机来一道、点进菜单。
- **云同步（可选）**：顶栏「云同步」用账号登录（旧同步码仍可用，并可升级为账号）。结构化记录存 Cloudflare D1，配图按内容哈希存 R2。**上传**以本机为准（含删除），**下载**用云端覆盖本机，两边不自动合并；后台自动备份只会在云端没有更新、且本机菜谱不少于云端时上传，只有本机从未编辑过时才会自动从云端恢复。每次覆盖云端前都会把上一版备份到 R2（保留最近 10 份 + 30 天内每天一份），备份失败则不覆盖。

## 启动

```bash
npm install
npm run dev -- --port 5173        # 本地开发（纯前端，不连线上云端）
npm test                          # 单元测试（node:test，含同步决策、云端备份、接口加固）
npm run check                     # 检查跨模块缺失导入
npm run format                    # Prettier 格式化
npm run build                     # 生产构建 → dist/
npm run deploy                    # 构建并发布到 Cloudflare Pages
```

本地联调云同步：`npm run build && npx wrangler d1 migrations apply shiji-sync --local && npx wrangler pages dev dist`，页面在 localhost 上会使用本地的 D1 / R2 / KV，不会读写线上数据。CI 在发布 GitHub Pages 前依次运行格式检查、导入检查、测试和构建。

## 说明与限制

- 通知基于浏览器 Notification API：页面打开时检查（临期提醒、前一天 18:00 备菜提醒）；iOS 需将网页添加到主屏幕。
- 邮件发送通过 `mailto:` 调起本机邮件应用，静态网页无法后台直接发送邮件。
- 图片上传自动压缩（主图最长边 1400px、步骤图 800px）后按内容哈希存入本机 IndexedDB，localStorage 里的菜谱 JSON 只保留引用；导出备份会把配图内联进 JSON，方便搬家；云同步只增量上传云端没有的配图。IndexedDB 不可用时回退为内联存储。
- 初次使用自带示例菜谱、冰箱、日用品和外出记录，可自行删除。
