# 食记 · 厨房伴侣

轻量的中文厨房管理网页：菜谱、本周菜单、冰箱库存、热量统计，纯前端 + 浏览器本地存储，无需服务器。

**线上地址（已固定，长期不变）：**

- **GitHub Pages（主地址，分享给他人用这个）**：https://ricardo121380.github.io/shiji-recipe/
- Cloudflare Pages（备用线路）：https://shiji-recipe.pages.dev/

两条线路网址长期固定，后续更新只替换内容、不改网址。菜谱数据按「网址 + 浏览器」隔离，请固定使用同一网址访问；跨线路搬家用「导出备份 / 导入备份」。详见 [AGENTS.md](AGENTS.md) 中的网址与数据约定。

## 功能

- **菜谱**：烹饪菜与零食速食两个板块；名称、分类、用时（小时/分钟）、人份、热量、简介、配图；食材按「名称 + 用量」结构化记录；步骤可配图，可勾选「需要提前准备」（如提前发酵）；分类可自定义（改名会同步到所有记录）。
- **本周菜单**：7 天 × 早/午/晚/加餐 四餐段；菜谱、零食、外出餐都能排入，可选日期；吃完点 ✓ 自动记录当日餐次并扣减冰箱库存（扣减前确认，可取消）。
- **冰箱**：库存数量、生产日期、保质期、低量提醒；猫 / 狗能否吃分别标注（能吃 / 谨慎 / 不能）；过期与临期（2 天内）预警横幅 + 浏览器通知（每天最多弹一次）；同一食材再次添加时从「最近添加」一键带出保质期等信息；支持手动 ± 调整库存。
- **购买清单**：按本周菜单自动汇总食材缺口（扣除冰箱已有、按单位匹配），可手动添加、勾选、清空。
- **吃过记录**：按自然月保存，自动清理两个月前的数据；月初可把上月清单复制或通过邮件应用发送（含日期和菜品名）。
- **热量**：自定义每日目标；今日摄入、剩余额度、本月每日明细；数据来自吃完记录中填写了热量的条目。
- **今天吃什么**：根据冰箱库存、临期食材和今日热量余量综合推荐菜谱，并说明推荐理由。
- **外出就餐**：外卖 / 饭店 / 食堂分类可编辑，记录热量与用时，可排进本周菜单。
- **数据**：全部保存在当前浏览器 localStorage，支持导出 JSON 备份；不同域名（两条线路）的数据相互独立。

## 启动

```bash
npm install
npm run dev -- --port 5173        # 本地开发
npm run build                     # 生产构建 → dist/
npm run deploy                    # 构建并发布到 Cloudflare Pages
```

## 说明与限制

- 通知基于浏览器 Notification API：页面打开时检查临期食材并弹窗；iOS 需将网页添加到主屏幕后才支持。
- 邮件发送通过 `mailto:` 调起本机邮件应用，静态网页无法后台直接发送邮件。
- 图片上传自动压缩（主图最长边 1400px、步骤图 800px）后以 dataURL 存入 localStorage；存储空间不足时会提示并回滚。
- 初次使用自带示例菜谱、冰箱库存和外出记录，可自行删除。
